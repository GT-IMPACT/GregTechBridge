В этой версии отдельный GT-миксин не нужен: `ModAndClassUtil` проверяет наличие `gregtech.api.recipe.RecipeMap`, при его отсутствии выбирает `GT5`, а не `GT5NH`. Impact попадает в поддержанную upstream ветку старого GT5. В исходниках целевого релиза не обнаружены прямые вызовы переименованных классов GregTech. Совместимость с новым AE2 обеспечивается выбором согласованного набора версий.

| Зависимость | Требование / ограничение | Наше состояние |
| --- | --- | --- |
| AE2 | В `@Mod` заявлено `rv3-beta-238` или новее; это старый порог, не гарантия для современного API | 1082-GTNH; upstream собирает FC с 1078-GTNH |
| NEI | API-зависимость опубликованного артефакта; runtime-минимум из номера компиляции не следует | 2.8.158-GTNH |
| GTNHLib | API-зависимость; upstream 0.11.37 | В dev-запуске 0.11.52 |
| Waila | API-зависимость опубликованного артефакта; `after:waila` в `@Mod` | Транзитивная 1.19.31 |
| WirelessCraftingTerminal / ThaumicEnergistics | Optional-интеграции с порядком загрузки | WCT 1.12.16 присутствует через NEE; ThaumicEnergistics не добавлялся |
| ExtraCells2 / Forestry / EnderIO / OpenComputers | Optional compile-интеграции | Не добавлены как обязательные зависимости моста |

Сборка и клиентские стадии инициализации прошли. Жидкостные шаблоны GT, dual interface, fluid storage bus, автокрафт и перенос старых хранилищ отдельно в мире не проверялись. Последний релиз оптимизирует поиск запасов ME Level Maintainer; это не исправление API Impact.
