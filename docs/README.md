## Как читать таблицы

**Тип** описывает характер изменения: совместимость/API, зависимость, исправление, функциональность, производительность, интерфейс или сборка. **Критичность** — оценка для нашей миграции, а не категория разработчиков upstream:

| Критичность | Значение |
| --- | --- |
| Критическая | Без исправления или обязательной зависимости невозможен запуск |
| Высокая | Краш, зависание, нарушение совместимости API или утрата/неверное восстановление состояния |
| Средняя | Ошибки расчётов, обработки предметов, новые функции, существенное изменение поведения |
| Низкая | Косметика, локализация, обслуживание сборки и небольшие оптимизации |
| Не определена | В release notes недостаточно данных для оценки |

Оценка записи релиза не доказывает, что ошибка возникала именно в нашей сборке. Для промежуточных версий отдельные игровые прогоны не выполнялись. Для целевых версий отдельно указаны проверенные сценарии и ограничения.

**Минимальная версия** приводится только при наличии ограничения в загрузчике/API либо как явно подписанный проверенный минимум. Версия в upstream `dependencies.gradle` часто является версией компиляции и не задаёт минимум для конечного пользователя. Optional-интеграции не становятся обязательными зависимостями.

## Источники и актуализация

История взята из официального GitHub Releases API; требования — из исходников соответствующих тегов, опубликованных Maven-метаданных и конфигурации проекта. Ссылки приведены в документах модов. Полный список NEI включает опубликованные релизы и prerelease в диапазоне, но не непубликовавшиеся теги и отдельные коммиты. Номер версии сортируется численно; prerelease не является рекомендуемой остановкой миграции.

При следующем обновлении нужно изменить целевую версию, таблицы релизов и зависимостей, перечислить новые исправления моста и отдельно отметить реально выполненные проверки. Новые минимумы нельзя выводить только из успешной компиляции.
