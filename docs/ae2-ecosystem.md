# Дополнительные моды экосистемы AE2

Проверка **11.10.2026**: официальные репозитории GTNH, исходники указанных релизов и default branches музейных проектов. Таблица относится к Minecraft 1.7.10. Отсутствие прямых ссылок GT не гарантирует совместимость всех функций с новым AE2.

| Мод | Версия / источник проверки | Результат |
| --- | --- | --- |
| [WirelessCraftingTerminal](https://github.com/GTNewHorizons/WirelessCraftingTerminal/releases/tag/1.12.16) | 1.12.16 | Прямых обращений к GregTech в Java-исходниках не найдено. Уже подключён транзитивно через NEE; загрузился с новым AE2. Работа терминала в мире отдельно не проверялась |
| [ThaumicEnergistics](https://github.com/GTNewHorizons/ThaumicEnergistics/releases/tag/1.7.64-GTNH) | 1.7.64-GTNH | Прямых обращений к GregTech не найдено. Аддон эссенции требует отдельного окружения Thaumcraft; не добавлен и не проверялся в клиенте |
| [AE2 Stuff](https://github.com/GTNH-Museum/ae2stuff) | Последний релиз 0.10.20-GTNH; код default branch | Перенесён в GTNH-Museum. В старом визуализаторе есть GTNH crafting-input hatches, защищённые `gregtech_nh`; Impact этот modid не использует. Современный AE2 уже имеет advanced inscriber, crystal growth chamber и network visualiser; установка старого аддона не требуется для этих функций |
| [ExtraCells2](https://github.com/GTNH-Museum/ExtraCells2) | Последний релиз 2.5.35; код default branch | Перенесён в GTNH-Museum. Прямых обращений к GregTech в Java/Scala не найдено. FluidCraft имеет настройку `replaceEC2` и собственные fluid cells / buses; замена EC2 в существующем мире требует отдельной проверки сохранённых предметов и блоков |

Расширенные интеграции с RemoteIO, OpenComputers, Forestry, EnderIO и Thaumcraft — самостоятельные сценарии. Они не становятся обязательными требованиями GregTechBridge. Поиск репозиториев GTNH по AE2/Energistics и проверка upstream dependencies не выявили другого активного специализированного AE2-аддона, требующего отдельного моста к Impact в рамках этого набора; это не аудит каждого стороннего мода.

AE2 Stuff стал избыточен после переноса его функций в основной AE2: там доступны advanced inscriber, crystal growth chamber, wireless connector / hub и network visualiser. [PR #734](https://github.com/GTNewHorizons/Applied-Energistics-2-Unofficial/pull/734), объединённый 20.05.2026, добавил Super Wireless Kit и конвертер старых объектов AE2 Stuff. Это объясняет перенос аддона в музей; отдельное объявление о причине переноса не найдено. Конвертер запускается только при наличии Postea: для существующего мира нельзя считать простое удаление старого JAR проверенной миграцией. Перенос мира Impact пока не проверен.
